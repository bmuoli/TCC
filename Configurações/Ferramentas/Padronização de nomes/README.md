# Padronização de nomes

Ferramenta legada para aplicar o manifesto `renomeacoes.csv` aos arquivos do Lab Notebook.

- Execute `Padronizar_Nomes_TCC.bat`.
- O alvo padrão é `Lab Notebook - HTML`.
- A opção de aplicação cria cópias em `Backups` antes de alterar nomes ou JSONs.
- A pasta `Notas` preserva o registro do reparo anterior.

O Lab Notebook atual não depende desta ferramenta para abrir ou sincronizar com o GitHub.
