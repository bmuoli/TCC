# TCC Lab Notebook — salvamento local

O Lab Notebook não cria checkpoints, commits nem faz push para o GitHub.

1. Abra `Iniciar_TCC_Lab_Notebook.bat` e mantenha a janela do auxiliar aberta.
2. No navegador, conecte a pasta `Lab Notebook - HTML` quando solicitado.
3. Trabalhe normalmente: as imagens são gravadas localmente em segundo plano.
4. Antes de fechar, clique em **Salvar tudo na pasta**. O HTML aguarda a fila de imagens, tenta novamente qualquer item pendente, grava `dados.json`, `campanha.json` e `resumo.csv` e confere os arquivos.

O auxiliar local serve apenas o HTML e permite ler evidências com caminhos longos no Windows. O endpoint antigo de sincronização está bloqueado e a execução de Git está desativada.
